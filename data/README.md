#Overview

This folder contains all datasets used in the Multi-Agent AI System for Academic Assistance project.

##Raw Data

courses.xlsx

Contains course details such as Course ID, Course Name, Department, Credits, and Faculty information.
Used to provide course-related information to students.

students.csv

Contains student information such as Student ID, Name, Department, Semester, and CGPA.
Used for student profile management and academic analysis.

faq.json

Contains frequently asked questions and answers.
Used by the chatbot to answer common academic queries.

syllabus.pdf

Contains the Artificial Intelligence course syllabus.
Used to provide syllabus and course-content information.

##Cleaned Data

courses_cleaned.xlsx

Validated course dataset after checking consistency.

students_cleaned.csv

Cleaned student dataset with duplicate and missing-value issues resolved.

faq_cleaned.json

Verified and validated FAQ dataset.

syllabus_cleaned.pdf

Validated syllabus document prepared for further processing.

Purpose

These datasets are used for academic assistance, query handling, data analysis, and future AI model development.
