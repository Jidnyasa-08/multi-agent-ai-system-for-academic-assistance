FRONTEND INTERFACE WIREFRAME

Purpose

The frontend interface allows students to interact with the Academic Assistant Application and receive responses from the Multi-Agent AI System.

Main Components

Header
Academic Assistant Application

Input Area
A text box where students can enter academic questions.

Submit Button
Sends the question to the backend API.

Response Area
Displays responses generated by:
- FAQ Agent
- Course Agent
- Student Agent
- Syllabus Agent

Navigation Options (Future Scope)
- Ask Question
- Generate Quiz
- Generate Summary
- View History

User Flow

1. Student enters a question.
2. Student clicks Submit.
3. Request is sent to the Flask backend API.
4. The router selects the appropriate AI agent.
5. The agent processes the query.
6. Response is returned to the frontend.
7. Response is displayed to the user.
