Frontend Interface Wireframe

Purpose

The frontend interface allows students to interact with the Academic Assistant Application.

Main Components

Header

Academic Assistant Application

Input Area

A text box where students can enter academic questions.

Submit Button

Sends the question to the backend server.

Response Area

Displays the AI-generated response.

Navigation Options

- Ask Question
- Generate Quiz
- Generate Summary
- View History

User Flow

1. Student enters a question.
2. Student clicks Submit.
3. Request is sent to the backend server.
4. AI system processes the request.
5. Response is displayed on the screen.
