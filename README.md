## Project Description

Multi-Agent AI System for Academic Assistance designed to provide learning support, intelligent educational guidance, academic information retrieval, and resource recommendations for students.

## Technologies Used

- Python
- Flask
- Pandas
- HTML
- CSS
- JavaScript
- GitHub

## Project Features

- FAQ Question Answering
- Student Information Retrieval
- Course Information Retrieval
- Syllabus Information Retrieval
- Multi-Agent Architecture
- Academic Assistance Chat Interface
- REST API using Flask

## Datasets Used

- FAQ Dataset (JSON)
- Student Dataset (CSV)
- Course Dataset (XLSX)
- Syllabus Dataset (PDF)
