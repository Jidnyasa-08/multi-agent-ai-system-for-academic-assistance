# Deployment

## Objective

Deploy the Multi-Agent AI System for Academic Assistance and verify that the backend is running successfully.

---

## Deployment Environment

- Operating System: Windows 11
- IDE: Visual Studio Code
- Programming Language: Python
- Framework: Flask
- API Testing Tool: Thunder Client

---

## Steps to Run

### Step 1: Open the project

Open the project folder in Visual Studio Code.

### Step 2: Open Terminal

Open the integrated terminal in Visual Studio Code.

### Step 3: Navigate to the project folder

If you are not already inside the project folder, run:

```bash
cd multi-agent-ai-system-for-academic-assistance
```

> **Note:** If your local project folder has a different name, replace the folder name with your own project folder.

### Step 4: Navigate to the source folder

```bash
cd src
```

### Step 5: Run the application

```bash
python app.py
```

### Step 6: Open the application

Open the following URL in your browser:

```
http://127.0.0.1:5000/
```

### Step 7: Verify Deployment

If the deployment is successful, the browser displays:

```
Academic Assistant Multi-Agent Backend Running
```

The backend is now running successfully and is ready to receive API requests.

- Backend Running Successfully

The Multi-Agent AI System for Academic Assistance was successfully deployed on the local machine using Flask. The application started without errors, and the backend was verified by opening the application in the browser and testing the API using Thunder Client.
