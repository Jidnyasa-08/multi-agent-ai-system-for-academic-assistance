# System Architecture

## Project Title
Multi-Agent AI System for Academic Assistant Application

## Objective
To design an Academic Assistant system using a Client-Server Architecture that allows students to ask academic questions and receive AI-generated responses.

## Components

### 1. Client Layer
The user interface where students interact with the application.

### 2. Server Layer
Handles requests from users and communicates with AI agents.

### 3. AI Agent Layer
Contains specialized agents:
- Academic Agent
- Quiz Agent
- Summary Agent

### 4. Database Layer
Stores user information, chat history, and feedback.

## Architecture Flow

User → Frontend → Backend Server → AI Agents → Database
